ELITE GYNAECOLOGY LAHORE - QUICK START

1) Make sure MongoDB is running locally.

2) Backend:
   cd backend
   npm install
   npm run seed
   npm run dev

3) Frontend (new terminal):
   cd frontend
   npm install
   npm run dev

4) Open:
   http://localhost:5173
